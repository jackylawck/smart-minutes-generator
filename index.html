Key Capabilities / 核心特色

📄

高質感 Word (.docx) 匯出

內建深藍商務標頭、精確欄寬與 OpenXML 防跨頁斷裂格式，下載即可直接提交高層與董事會。

🎯

動態範本結構映射

支援內建 3 大商務範本 (週會、董事會、專案檢討) 或上傳企業專屬 Word 範本，自動保持原本 Logo 與議題骨架。

🔑

BYOK 企業通道與安全防護

支援輸入企業專屬 API Key，內建 Session Rate Limiting 與安全 Exception 攔截，嚴防 API Key 與敏感資料外洩。

🛡️ ISO 資安與隱私合規設計 (Privacy-by-Design)

🔒 ISO/IEC 27001 零數據留存 (ZDR)

採用純 Session-Only 記憶體運算架構。上傳之簡報與生成紀錄絕不儲存於任何伺服器硬碟或資料庫，瀏覽器一經關閉或重新整理，所有記憶體資料即刻徹底銷毀。

🔒 ISO/IEC 27701 本地 PII 假名化

於資料送出 API 前，本地 Python 端 (`PIIMasker`) 先將香港身份證 (HKID)、電話、薪資金額等敏感個資進行假名化遮蔽，收回回應後再於本地端還原，防止第三方 LLM 接觸真實敏感資料。
