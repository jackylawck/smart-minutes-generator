🛡️ ISO 資安、隱私與 AI 治理設計 (AIMS & Privacy Compliance)

🔒 ISO 27001 (ZDR 零留存)

純 Session-Only 記憶體運算架構。上傳檔案與生成紀錄絕不留存硬碟或資料庫，分頁關閉即刻銷毀。
Zero disk persistence with instant garbage collection upon session termination.

🔒 ISO 27701 (本地 PII 假名化)

送往 API 前於本地端正則遮蔽 HKID、電話、Email 與薪資，收回結果再於本地遞迴還原，第三方 LLM 0% 接觸個資。
Pre-flight local pseudonymization ensuring zero sensitive data exposure to cloud LLMs.

🔒 ISO 42001 (AIMS 審計軌跡)

自動記錄脫敏 Token 數、模型調度版本與執行狀態，支援一鍵匯出 Audit Log JSON 文件供 CISO 查驗。
Built-in session audit trail exportable as JSON for ISO 42001 AI governance audits.
