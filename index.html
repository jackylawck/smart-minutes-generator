🛡️ ISO 資安與隱私合規設計 (Privacy-by-Design & Compliance)

🔒 ISO/IEC 27001 零數據留存 (Zero Data Retention / ZDR)

採用純 Session-Only 記憶體運算架構。上傳之簡報與生成紀錄絕不儲存於任何伺服器硬碟或資料庫，瀏覽器一經關閉或重新整理，所有記憶體資料即刻徹底銷毀。
Session-only in-memory architecture. Files and generated text are never persisted to disk or databases and are instantly destroyed when the browser session ends.

🔒 ISO/IEC 27701 本地 PII 假名化 (Local PII Redaction)

於資料送出 API 前，本地 Python 端 (`PIIMasker`) 先將香港身份證 (HKID)、電話、薪資金額等敏感個資進行假名化遮蔽，收回回應後再於本地端還原，防止第三方 LLM 接觸真實敏感資料。
Pre-flight local anonymization for HKID, phone numbers, and salary details before sending to LLMs, ensuring compliance with privacy standards.
