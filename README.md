# 📝 智能會議記錄生成器 (Smart Minutes Generator)

基於 **Streamlit**、**GitHub Models (GPT-4o-mini)** 與 **動態範本映射技術 (Dynamic Template Mapping)** 開發的通用企業級會議記錄自動化工具。

🌐 **線上使用網址：** [https://smart-minutes-generator.streamlit.app](https://smart-minutes-generator.streamlit.app)

---

## ✨ 核心特色與功能

* **🔒 Privacy-First / 遵循 ISO 資安標準設計：** 採用 **Session-Only 記憶體即時運算**，使用者上傳的檔案與生成結果在關閉網頁後即刻徹底銷毀，遵循 ISO 27001 數據最小化與 Zero Data Retention (ZDR) 原則。
* **📋 動態結構映射 (Dynamic Structure Mapping)：** 無需預設死板的議題大項。系統會自動閱讀您上傳的 Word 格式範本，提煉其「編號與議題標題」作為骨架，將新內容精準對號入座。
* **📊 雙模式內容輸入：**
  * **模式 A (PPT 簡報)：** 上傳簡報檔，AI 自動解析頁面標題、內文與備註欄 (Notes)。
  * **模式 B (文字草稿)：** 無 PPT 時，可直接於網頁輸入框按層級格式 (如 `1.1 ... 1.2 ...`) 貼上會議紀錄草稿。
* **📥 基準範本下載：** 側邊欄內建標準通用型會議記錄格式範本 (`meeting_template.docx`)，方便未備有範本的使用者即時下載套用。

---

## 📖 使用指南 (User Guide)

1. **下載或準備範本：** 於側邊欄下載《空白會議記錄格式範本 (.docx)》，或使用貴單位上次的會議記錄作為基準骨架。
2. **上傳基準範本：** 將 Word 檔案上傳至「1. 上傳會議記錄格式範本 / 上次紀錄」。
3. **提供本次會議內容 (二選一)：**
   * **選擇 A：** 上傳本次會議簡報 (`.pptx`)。
   * **選擇 B：** 直接於文字框貼上會議草稿 (請按 `1. 議題` -> `1.1 子項目` 層級輸入)。
4. **生成與下載：** 點擊「🚀 即刻依範本結構生成會議記錄」，預覽結果無誤後，即可點擊下載 Markdown 格式檔案。

## 📌 PPT 製作與輸入建議

為確保 AI 能 100% 精準擷取會議決議與數據，上傳的 PPT 頁面建議遵循以下結構：

* **頁面頂部：** 主議題 (對應範本大標題，如 `三、營運及專案進度`)
* **頁面中間：** 子題目 (對應項目編號，如 `3.1 伺服器遷移計劃`)
* **頁面下方：** 詳細文字內容 (具體決議、數據或名單)

> ⚠️ **注意事項：** 請使用純文字框呈現代辦或決議事項。若內容為截圖/圖片，程式無法讀取圖片內文，該項目將僅顯示子題目名稱。

## 🛡️ 資安與隱私聲明 (Security & Privacy)

* **零資料留存 (Zero Data Retention)：** 本系統採用純 Session 記憶體處理，使用者上傳之 `.docx` 及 `.pptx` 檔案不會儲存於任何伺服器硬碟、資料庫或 GitHub 儲存庫。
* **傳輸安全 (TLS/SSL)：** 網頁傳輸與 API 連線全程採用 HTTPS / TLS 加密。
* **Secrets 管理：** API 密鑰儲存於受保護的環境變數中，確保憑證不外洩。
* **架構合規：** 系統設計遵循 ISO/IEC 27001 (資訊安全管理) 及 ISO/IEC 27701 (隱私資訊管理) 之「數據最小化」與「機密性保護」原則。

## 🛠️ 技術架構 (Tech Stack)

* **前端與 UI：** Streamlit
* **大語言模型 API：** GitHub Models / Azure OpenAI (`gpt-4o-mini`)
* **文件解析庫：** `python-docx` (解析 Word) + `python-pptx` (解析 PPT 與備註欄)
* **樣式優化：** Custom CSS (控制 Markdown 表格寬度與決議欄不換行)
